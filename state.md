## Product outcome

MoonWaker will let the user choose a profile after choosing a host, protect individual profiles with an optional four-digit app PIN, show whether the selected MoonWaker profile matches the active Windows session, and explicitly switch Windows users without logging anybody off.

The target entry flow is:

```text
Host selection
  -> one usable profile without PIN: enter host
  -> one usable profile with PIN: PIN screen -> enter host
  -> several profiles with valid automatic app profile: enter host
  -> several profiles without automatic app profile: profile selection
       -> unprotected profile: enter host
       -> protected profile: PIN screen -> enter host
```

Profile selection in the app and switching the active Windows desktop are separate intents. Entering or refreshing the host screen must never switch Windows automatically.

## Non-negotiable decisions

1. Switch Windows users through Fast User Switching by disconnecting the active console session. Never log it off.
2. Preserve the previous user's applications and session.
3. Treat profile mismatch as yellow attention, not offline.
4. Insert a profile gate between host selection and profile-scoped library loading.
5. Store an automatic app profile per host only. It never silently switches Windows.
6. PIN-protected profiles cannot use unattended automatic app login.
7. Android never stores or logs the PIN. Gateway verification and a short server-side unlock lease are mandatory.
8. `use_profile` and `remote_sign_in` remain authorization boundaries.
9. A Windows switch is a separate explicit Gateway mutation. Do not add switching side effects to `session/ensure`.
10. Preserve PlayIntent correlation, LaunchTransitionController privacy rules, and Moonlight core boundaries.

## UI contract

### Host presentation

| Windows/App state | Presentation |
|---|---|
| PC Basia, MoonWaker Basia | Green; `Profil: Basia` |
| PC Gry, MoonWaker Basia | Yellow; `MoonWaker: Basia · PC: Gry` |
| Active PC profile is unavailable to the client | Yellow; `Basia · aktywny inny profil PC` |
| Basia locked, disconnected, or signed out | Yellow; `Basia · wymaga zalogowania` |
| Session state unknown | Yellow; `Basia · sprawdź profil PC` |
| Host offline | Existing red offline presentation |

Existing active-stream, retained, suspended, terminating, waking, and offline presentation keeps precedence over the new idle-online profile-attention refinement.

### Profile selection screen

Use a MoonWaker-styled, PS5-inspired full-screen layout:

```text
Wybierz profil

        [ avatar ]              [ avatar ]
          BASIA                    GRY
          PIN                    Aktywny na PC

X/A Wybierz       O/B Wstecz       OPTIONS Opcje
```

- Large horizontal profile tiles.
- Focused tile scales slightly and receives a bright outline.
- Mark the active Windows profile, the PIN requirement, and the automatic app profile in text as well as visually.
- `OPTIONS` on an unprotected profile toggles `Loguj automatycznie jako <name>`.
- Back returns to host selection and restores focus to the originating host.

### PIN screen

```text
Wprowadź PIN

      [ avatar ]            *  *  _  _
        BASIA

                       1 Left    2 Up      3 Right
                       4 Down    5 R1/RB   6 R2/RT
                       7 L1/LB   8 L2/LT   9 Triangle/Y
                                  0 Square/X

                       O/B Usuń lub wróć
```

- Four digits auto-submit.
- A/Cross can submit; B/Circle deletes, then returns when empty.
- Wrong PIN clears the entry after bounded visual feedback.
- A non-gamepad TV remote uses a focusable 0–9 keypad with D-pad and OK.
- Physical numeric keys are accepted.
- No entered digit may reach logs, diagnostics, saved state, or screenshots generated by tests.

6. Never store secrets, PINs, passwords, tokens, certificate material, or raw diagnostics here.
7. Do not commit or push unless the user explicitly asks.
